1. 铁磁性材料为什么能大幅加强磁场

（对应教材 p185）

最直接的一句话答案

铁磁性材料内部有自发磁化的磁畴，外磁场一来磁畴集体转向，产生的磁化强度 M 比非铁磁材料大几万到几百万倍，而总磁感应强度 B = μ₀(H + M)，M 一大 B 就被大幅拉高。

对比一看就懂

真空/非铁磁质：M ≈ 0 → B = μ₀H，B 和 H 几乎一样大

铁磁质：M ≫ H → B ≈ μ₀M，B 由 M 主导，比 μ₀H 大得多

材料 磁化率 χₘ = M/H M 的量级 总 B
真空 0 0 B = μ₀H
顺磁质（如铝） ~10⁻⁵ 极小 B ≈ μ₀H，微微增强
抗磁质（如铜） ~−10⁻⁵ 极小且反向 B ≈ μ₀H，微微减弱
铁磁质（铁/钴/镍） 10³ ~ 10⁶ 极大 B ≫ μ₀H，被大幅加强

微观机理（磁畴理论）

这是铁磁质能产生大 M 的根本原因：

  1. 自发磁化：铁磁质内部的原子电子自旋磁矩之间存在交换耦合作用，使得相邻原子的磁矩自发地平行排列，形成一个个微小的自发磁化区域——磁畴（尺度 ~10⁻⁶ m）
  2. 无外场时：各磁畴方向杂乱无章，总体 M = 0，不显磁性
  3. 加外场时：磁畴通过畴壁位移和磁矩转动逐步转向外磁场方向，M 迅速增大
  4. 饱和：所有磁畴对齐后，M 达到最大值（饱和磁化强度 Mₛ），再加大外场 M 也不再增加

B-H 曲线（磁化曲线）

铁磁质的 B 和 H 非线性（因为磁畴转向不是线性过程），且存在磁滞回线（H 减小到零时 B 还剩一点——剩磁）。这是非铁磁质没有的。

一句话总结

铁磁质的 M 极大（来自磁畴自发磁化 + 外场对齐）→ B = μ₀(H+M) 中 M 主导 → B 被大幅加强。

2. 恒定电流场中，为什么电流不能在无源导电区域突然中断

（对应教材 p146）

最直接的一句话答案

因为电荷守恒 + 恒定条件要求 ∇·J = 0，也就是流入无源区域的电流必须等于流出的电流——没有电荷凭空消失或产生的地方，电流就断不了。

从”突然中断”的矛盾说起

假设电流在某个无源区域真的突然中断了，会发生什么？

  • 流进来的电荷 > 流出去的电荷 → 电荷会在断点处积累
  • 或者流出去的 > 流进来的 → 断点处缺电荷
  • 但题目说”无源导电区域”——没有电源来维持电荷积累，电荷分布是恒定的
  • 所以矛盾了：∂ρ/∂t = 0 要求 ∇·J = 0，不允许流进流出不一样

用方程推一遍（必须会写）

第一步：电荷守恒定律（不会错的基本规律）

任意闭合曲面 S 内的电荷变化率 = 流入的电流 − 流出的电流：

$$\oint_S \mathbf{J} \cdot d\mathbf{S} = -\frac{dQ}{dt} = -\int_V \frac{\partial \rho}{\partial t} dV$$

左边是流出 S 的总电流（正的流出，负的流入），右边是曲面内电荷的减少率。整个式子就是：流出的电流 = 内部电荷减少的速率。

第二步：散度定理把曲面积分变体积分

$$\int_V (\nabla \cdot \mathbf{J}) \, dV = -\int_V \frac{\partial \rho}{\partial t} dV$$

这个对任意体积 V 都成立，所以被积函数必须相等：

$$\boxed{\nabla \cdot \mathbf{J} = -\dfrac{\partial \rho}{\partial t}} \quad \text{（电流连续性方程的一般形式，任何时刻都成立）}$$

第三步：加上”恒定”条件

恒定电流 ⇔ 电荷分布不随时间变化 ⇔ ∂ρ/∂t = 0

代入上式立刻得到：

$$\boxed{\nabla \cdot \mathbf{J} = 0} \quad \text{（恒定电流场的基本方程）}$$

∇·J = 0 到底是什么意思？（三种理解方式）

理解角度 含义
数学 在无源区域内，电流密度 J 的散度处处为零
积分 任取一个闭合曲面，流入的电流 = 流出的电流，净流出 = 0
物理图像 电流线（J 线）是闭合曲线，起点和终点都不能在无源区域内——起点只能在电源正极，终点只能在电源负极

那电流在哪里”产生”和”消失”？

只能在有源区域：

  • 电源内部：非库仑力把正电荷从负极搬到正极，电流从负极流向正极（和外电路反着）
  • 有电荷变化的地方：电容器极板充电时，电流在极板处终止（但这是时变场，不是恒定场）

恒定电流场里，整个电路的电流线必须闭合：从电源正极出来，经过外电路，回到电源负极，在电源内部再回到正极——一个完整的闭合回路，没有任何地方中断。

一句话总结

无源导电区域里 ∂ρ/∂t = 0，由电荷守恒 ∇·J = −∂ρ/∂t 就得 ∇·J = 0 → 流进 = 流出 → 电流线不能终止 → 不能突然中断。

3. 边界条件（静电场 / 恒定电场 / 恒定磁场）

边界条件就是场量在两种不同介质分界面两侧必须满足的约束关系。记住：法向分量的跃变由自由电荷/电流决定，切向分量的跃变由面电流决定。

3.1 静电场边界条件

设分界面法向单位矢量 n 从介质 2 指向介质 1，界面上自由电荷面密度为 σ。

场量 法向分量（n 方向） 切向分量（界面内）
电场强度 E E₁ₙ − E₂ₙ = σ / ε₀ （真空时）
一般：D₁ₙ − D₂ₙ = σ		 E₁ₜ = E₂ₜ （始终连续）
电位移 D D₁ₙ − D₂ₙ = σ D 的切向分量一般不连续
电位 φ φ₁ = φ₂ （连续） —

核心公式：

  • 法向：n·(D₁ − D₂) = σ
  • 切向：n × (E₁ − E₂) = 0

3.2 恒定电场边界条件

恒定电场满足 J 的边界条件（核心是电流连续）：

场量 法向分量 切向分量
电流密度 J J₁ₙ = J₂ₙ （电流连续，不能中断） —
电场强度 E — E₁ₜ = E₂ₜ （与静电场同）
电导率 γ 若 γ₁ ≠ γ₂，法向 E 会跃变 —

核心公式：

  • 法向：n·(J₁ − J₂) = 0
  • 切向：n × (E₁ − E₂) = 0

3.3 恒定磁场边界条件

设分界面上有面电流密度 K，法向 n 从介质 2 指向介质 1。

场量 法向分量 切向分量
磁感应强度 B B₁ₙ = B₂ₙ （磁通用连续，B 线闭合） —
磁场强度 H — n × (H₁ − H₂) = K
矢量位 A A₁ = A₂ （切向连续，规范选定后） —

核心公式：

  • 法向：n·(B₁ − B₂) = 0 （磁通连续性）
  • 切向：n × (H₁ − H₂) = K （安培环路的边界形式）

4. 麦克斯韦方程组：积分式 + 微分式 + 各自对应的定律及其物理意义

麦克斯韦方程组 = 库仑定律（高斯）+ 磁通连续性 + 法拉第电磁感应 + 安培环路 + 位移电流修正
它是四个方程的合成，统一了电场和磁场，是电磁场理论的基石。

4.1 四个方程的来源

序号 定律名称 积分形式 微分形式 物理意义
① 电场高斯定理（库仑定律推广） ∮_S D·dS = ∫_V ρ dV = Q_free ∇·D = ρ 电位移矢量的散度等于自由电荷密度，说明电场是有源场，电荷是电场的源
② 磁通连续性原理（磁场无单极子） ∮_S B·dS = 0 ∇·B = 0 磁感应强度的散度恒为零，说明磁场是无源场（无磁荷），B 线是闭合曲线
③ 法拉第电磁感应定律 ∮_C E·dl = −d/dt ∫_S B·dS ∇ × E = −∂B/∂t 时变磁场产生涡旋电场，说明变化的磁场是电场的旋度源
④ 安培-麦克斯韦环路定理（安培环路 + 位移电流） ∮_C H·dl = ∫_S J·dS + d/dt ∫_S D·dS ∇ × H = J + ∂D/∂t 时变电场（位移电流）和传导电流一样能产生磁场，说明变化的电场也是磁场的旋度源

4.2 位移电流的引入（老师重点提的”虚拟电流”）

麦克斯韦的关键贡献：在安培环路定理中加入了位移电流项 ∂D/∂t，使方程组自洽。

  • 位移电流密度：J_d = ∂D/∂t
  • 位移电流不是真实电荷的定向移动，但它和传导电流一样，都会在周围产生磁场
  • 引入位移电流后，安培环路定理对时变场也成立，不再局限于恒定电流场
  • 这也是麦克斯韦方程组能统一描述电磁波的关键

4.3 完整方程组汇总

积分形式：

$$ \begin{cases} \oint_S \mathbf{D} \cdot d\mathbf{S} = Q_{\text{free}} \\ \oint_S \mathbf{B} \cdot d\mathbf{S} = 0 \\ \oint_C \mathbf{E} \cdot d\mathbf{l} = -\frac{d}{dt} \int_S \mathbf{B} \cdot d\mathbf{S} \\ \oint_C \mathbf{H} \cdot d\mathbf{l} = I_{\text{free}} + \frac{d}{dt} \int_S \mathbf{D} \cdot d\mathbf{S} \end{cases} $$

微分形式：

$$ \begin{cases} \nabla \cdot \mathbf{D} = \rho \\ \nabla \cdot \mathbf{B} = 0 \\ \nabla \times \mathbf{E} = -\dfrac{\partial \mathbf{B}}{\partial t} \\ \nabla \times \mathbf{H} = \mathbf{J} + \dfrac{\partial \mathbf{D}}{\partial t} \end{cases} $$

5. 典型计算题考点

5.1 电阻计算（从工程电磁场角度）

方法： 不要只记 R = ρL/S，要会用 J → E → U → R 的场论思路。

$$R = \frac{U}{I} = \frac{\int \mathbf{E} \cdot d\mathbf{l}}{\int \mathbf{J} \cdot d\mathbf{S}} = \frac{\int \frac{\mathbf{J}}{\gamma} \cdot d\mathbf{l}}{\int \mathbf{J} \cdot d\mathbf{S}}$$

对于均匀导体，J 平行均匀时退化为 R = L/(γS) = ρL/S。

5.2 四分之一圆导体——两个截面之间的电阻

这是老师重点提的计算题。关键在于：电流方向不同，横截面积 S 是否随位置变化也不同，决定了是直接套 R = ρL/S 还是必须积分。

几何前提

四分之一圆导体在 xy 平面内：

  • 内半径 a，外半径 b
  • z 方向厚度 t（垂直于纸面）
  • 张角 α = π/2（90°）
  • 材料电阻率 ρ，电导率 γ = 1/ρ

下面分三种典型的”两个截面”组合分别求电阻：

情况 A：电压加在 θ=0 与 θ=π/2 两个端面之间（电流沿 θ 方向）

求： R_A

电流方向：θ 方向（沿圆弧绕行）
取一个微元段：在半径 r 处，沿 θ 方向取微元长度 dl = r·dθ

关键判断：横截面积 S 是否随 r 变化？

  • 垂直于 θ 方向的截面是一个矩形：从 r=a 到 r=b（径向宽度 b−a），z 方向厚度 t
  • 所以 S = (b−a)·t，在任何 r、任何 θ 处都一样，是常数 ✅

但注意：电流沿 θ 方向流动时，不同 r 处的弧长不同！这意味着 E_θ 和 J_θ 都会随 r 变化。

场论求解步骤：

  1. 设总电流 I 已知，用安培环路思路类似，考虑对称性：

    • 在半径 r 处取薄圆环，宽度 dr，厚度 t
    • 该薄圆环的横截面积为 dS = dr·t，流过的电流 dI = J_θ(r)·dr·t

  2. 整个导体的总电流 I = ∫ dI = ∫(r=a to b) J_θ(r)·t·dr

  3. 由欧姆定律微分形式：J_θ(r) = γ·E_θ(r)

  4. 在 θ 方向，从 θ=0 到 θ=π/2 的电压降：
    U = ∫(0 to π/2) E_θ(r)·r·dθ = E_θ(r)·r·π/2
    （这里对任意 r 都成立，因为两端面是等势面，U 与 r 无关）

  5. 联立得：E_θ(r) = 2U/(πr)，J_θ(r) = 2γU/(πr)

  6. 代入总电流积分：
    $$I = \int_a^b \frac{2\gamma U}{\pi r} \cdot t \, dr = \frac{2\gamma U t}{\pi} \int_a^b \frac{dr}{r} = \frac{2\gamma U t}{\pi} \ln\frac{b}{a}$$

  7. 由 R = U/I，整理得：

$$\boxed{R_A = \frac{\pi \rho}{2t \ln(b/a)}}$$

💡 要点：因为不同 r 处弧长不同导致 E_θ 随 r 变化，必须积分，不能直接套 R = ρ·L_arc/S（那是均匀截面的情况，这里截面虽然形状不变但 J 不均匀）。

情况 B：电压加在内弧面 (r=a) 与外弧面 (r=b) 之间（电流沿 r 方向）

求： R_B

电流方向：径向（从内弧面流向外弧面）
取微元：在半径 r 处，沿径向取微元长度 dr

关键判断：横截面积 S 是否随 r 变化？

  • 垂直于径向（r 方向）的截面是一个弧形面：弧长 = (π/2)·r，厚度 = t
  • 所以 S(r) = (πr/2)·t，随 r 增大而增大 ❌ → 必须积分！

场论求解步骤：

  1. 由对称性，E 只有 E_r 分量，且仅随 r 变化，E_r = E_r(r)

  2. 由欧姆定律：J_r(r) = γ·E_r(r)

  3. 电流连续性（∇·J = 0）要求：通过任一 r 处的总电流 I 相同
    $$I = J_r(r) \cdot S(r) = \gamma E_r(r) \cdot \frac{\pi r}{2} t$$

  4. 解得电场分布：E_r(r) = 2I/(γπ r t)

  5. 电压降（从 a 到 b）：
    $$U = \int_a^b E_r(r) dr = \int_a^b \frac{2I}{\gamma \pi t r} dr = \frac{2I}{\gamma \pi t} \ln\frac{b}{a}$$

  6. 由 R = U/I：

$$\boxed{R_B = \frac{2\rho}{\pi t} \ln\frac{b}{a}}$$

💡 要点：因为径向 S(r) = (πr/2)t 随 r 变化，必须积分，这是最典型的变截面电阻计算。

情况 C：电压加在”两个扇形尖端”（如 r=a,θ=0 与 r=b,θ=π/2）

这种情况电流既不沿纯 r 也不沿纯 θ，是 2D 混合流动，通常用数值方法或保角变换求解，属于较难的题型。考试中较少直接考这种配置，主要考 A 和 B 两种。

对比总结

情况 加电压的两个截面 电流方向 S 是否随位置变 电阻公式
A θ=0 端面 ↔ θ=π/2 端面 沿 θ（绕行） S = (b−a)t 不变 R = πρ / [2t·ln(b/a)]
B 内弧 r=a ↔ 外弧 r=b 沿 r（径向） S(r) = πrt/2 变大 R = 2ρ·ln(b/a) / (πt)

快速记忆：两个公式都是 ρ·ln(b/a) 除以 t，只是前面的系数不同（π/2 vs 2/π），系数的倒数关系来自两个方向电流的”对称性互逆”。

从工程电磁场角度看这类题的核心套路

不管什么形状导体求电阻，三步走：

  1. 确定电流方向 J，找到垂直于 J 的”等势截面”形状
  2. 判断 S 是否随位置变化：变就积分，不变就直接用
  3. 积分公式：$R = \int \rho \frac{dl}{S(l)}$，其中 dl 沿电流路径

5.3 “求 I1” 类分流电阻计算

典型场景：两个（或多个）并联支路求分流电流。

  • 方法 1（场论）：两条支路的 E 相同（并联电压相等），分别用 J = γE，再由总电流分配
  • 方法 2（电路）：I₁ = I·R₂/(R₁+R₂)，I₂ = I·R₁/(R₁+R₂)
  • 工程电磁场角度：确认并联支路电场切向相等、电流法向相等，再求解

5.4 有宽度的无限长铜导线（电流 I）内外磁场

设导线半径 a，电流 I 均匀分布（导体内部）。

用安培环路定理 ∮ H·dl = I_enclosed：

外部（r ≥ a）：

  • 包围全部电流 I_enclosed = I
  • H·2πr = I → H = I/(2πr)，B = μ₀I/(2πr) （和无限长细线一样）

内部（r < a）：

  • 电流均匀分布，I_enclosed = I·(πr²/πa²) = I·r²/a²
  • H·2πr = I·r²/a² → H = Ir/(2πa²)，B = μ₀Ir/(2πa²)
  • 内部 B 与 r 成正比，中心为零，r = a 处连续：B(a) = μ₀I/(2πa)

5.5 角量的电场强度（球坐标 E_r、E_θ、E_φ）

当电荷分布具有球对称性或轴对称性时，用分离变量法求解拉普拉斯方程或直接由高斯定理：

  • 球对称（如点电荷、带电球面）：只有 E_r 分量，E_θ = E_φ = 0
  • 轴对称（如电偶极子、带电圆盘）：可能有 E_r 和 E_θ，E_φ = 0
  • 常见电势分离变量解：φ(r,θ) = Σ (Aₙrⁿ + Bₙr⁻ⁿ⁺¹) Pₙ(cosθ)，E = −∇φ

6. 唯一性定理：是什么 / 有什么作用 / 有什么意义

6.1 是什么

唯一性定理：在给定的区域 V 内，当场的源（电荷分布 ρ 或电流分布 J）确定，且区域边界 S 上的边界条件（第一类 φ 值 / 第二类 φ 的法向导数 / 第三类混合条件）也确定时，区域 V 内的电磁场解是唯一的。

静电场唯一性定理

给定 V 内的 ρ(r) 和边界 S 上的 φ 值（或 ∂φ/∂n 值），则 V 内的电势 φ(r) 唯一确定。

恒定磁场唯一性定理

给定 V 内的 J(r) 和边界条件，则 V 内的矢量位 A(r) 和磁感应 B(r) 唯一确定。

6.2 有什么作用

  1. 允许用任何方法求解：只要构造的解同时满足基本方程（∇·D = ρ 等）和边界条件，就是正确解——不需要从泊松方程一步步解。
  2. 镜像法、分离变量法等间接解法的理论基础：镜像法找到满足边界条件的假想源，因为唯一性定理保证只要边界条件匹配就没问题。
  3. 检验解的正确性：解出后只需验证方程是否满足、边界条件是否满足即可。

6.3 有什么意义

  • 唯一性定理揭示了场的因果关系的确定性：给定源和边界，场唯一；没有”可能解”和”不可能解”的模糊地带。
  • 它是整个电磁场理论中最重要的存在性和唯一性保证，为所有求解方法提供了理论支撑。

7. 能量 & 能量密度：静电场 & 磁场

老师明确要求：不光要会写能量密度，还要会算能量，还要知道能量从哪来、怎么存。

7.1 静电场的能量

（1）能量密度（单位体积的电场能量）

$$w_e = \frac{1}{2} \mathbf{D} \cdot \mathbf{E}$$

  • 各向同性介质中：w_e = ½ εE² = D²/(2ε)
  • 物理意义：电场能量不是集中在电荷上，而是分布在整个有电场的空间中，哪里有 E 哪里就有能量

（2）总能量的三种计算方式

方式 公式 适用场景
场积分法（最本质） $$W_e = \iiint_V \frac{1}{2} \mathbf{D} \cdot \mathbf{E} \, dV$$ 已知 E(r) 或 D(r)，全空间或所有存在电场的区域积分
电位-电荷法 $$W_e = \frac{1}{2} \sum_i Q_i \varphi_i$$ 已知每个点电荷 Q_i 及其所在位置的电位 φ_i（由其他电荷产生）
电容法（电路近似） $$W_e = \frac{1}{2} C U^2 = \frac{Q^2}{2C}$$ 已知系统等效电容 C 和电压 U，或总电荷 Q

（3）能量来源

建立带电系统的过程中，外力克服电场力做功，这部分功全部转化为电场能量储存起来，没有耗散。

（4）典型系统的静电能计算

例 1：平行板电容器（面积 S，间距 d，电压 U）

  • 板间 E = U/d，D = εE = εU/d（均匀）
  • 场积分：W_e = ½ D·E · Sd = ½ (εU/d)(U/d) Sd = ½ εSU²/d = ½ CU² ✔（和电容法一致）

例 2：点电荷 Q 的自能（半径 a 的均匀带电球，电荷 Q，介质 ε）

  • 内部（r < a）：E = Qr/(4πεa³)
  • 外部（r > a）：E = Q/(4πεr²)
  • 全空间积分：
    $$W_e = \int_0^a \frac{1}{2}\varepsilon \left(\frac{Qr}{4\pi\varepsilon a^3}\right)^2 4\pi r^2 dr + \int_a^\infty \frac{1}{2}\varepsilon \left(\frac{Q}{4\pi\varepsilon r^2}\right)^2 4\pi r^2 dr = \frac{Q^2}{8\pi\varepsilon a}$$

7.2 磁场的能量

（1）能量密度（单位体积的磁场能量）

$$w_m = \frac{1}{2} \mathbf{B} \cdot \mathbf{H}$$

  • 各向同性介质中：w_m = ½ μH² = B²/(2μ)
  • 物理意义：磁场能量同样分布在整个有磁场的空间中，哪里有 B 哪里就有能量

（2）总能量的三种计算方式

方式 公式 适用场景
场积分法（最本质） $$W_m = \iiint_V \frac{1}{2} \mathbf{B} \cdot \mathbf{H} \, dV$$ 已知 B(r) 或 H(r)，全空间积分（电流分布区域内外都要算）
电流-矢量位法 $$W_m = \frac{1}{2} \iiint_V \mathbf{J} \cdot \mathbf{A} \, dV$$ 已知电流密度 J 和矢量位 A（仅在有电流的区域积分）
电感法（电路近似） $$W_m = \frac{1}{2} L I^2$$ 已知自感 L 和电流 I，或互感能量 ½M I₁I₂

（3）能量来源

建立电流系统的过程中，电源抵抗自感/互感产生的反电动势做功，这部分功转化为磁场能量储存起来。

（4）典型系统的磁场能计算

例 1：长直螺线管（长度 l，横截面积 S，匝数 N，电流 I，介质 μ）

  • 内部均匀 H = nI = NI/l，B = μNI/l
  • 外部 B ≈ 0，只需积分内部体积 V = Sl：
  • W_m = ½ B·H · Sl = ½ (μNI/l)(NI/l) Sl = ½ μN²I²S/l = ½ LI² ✔（和电感法一致，其中 L = μN²S/l）

例 2：无限长圆柱导线的磁场能（半径 a，电流 I 均匀分布，介质 μ₀）

  • 内部（r < a）：B = μ₀Ir/(2πa²)，H = Ir/(2πa²)
  • 外部（r > a）：B = μ₀I/(2πr)，H = I/(2πr)
  • 取单位长度（l = 1）积分：
    $$W_m = \int_0^a \frac{1}{2} \cdot \frac{\mu_0 I r}{2\pi a^2} \cdot \frac{I r}{2\pi a^2} \cdot 2\pi r dr + \int_a^\infty \frac{1}{2} \cdot \frac{\mu_0 I}{2\pi r} \cdot \frac{I}{2\pi r} \cdot 2\pi r dr = \frac{\mu_0 I^2}{16\pi} + \frac{\mu_0 I^2}{4\pi} \ln\frac{\infty}{a}$$
    （外部发散，因为无限长导线的自感本身就是无穷大，实际取有限长度即可）

7.3 静电场能量 vs 磁场能量——完整对比表

对比项 静电场能量 磁场能量
能量密度 w_e = ½ D·E = ½ εE² w_m = ½ B·H = ½ μH²
场积分公式 W_e = ∫ ½ D·E dV W_m = ∫ ½ B·H dV
做功来源 外力克服电场力对电荷做功 电源抵抗感应电动势对电流做功
做功积分形式 W_e = ½ Σ Q_i φ_i W_m = ½ ∫ J·A dV
电路形式 W_e = ½ CU² = Q²/(2C) W_m = ½ LI²
能量储存场所 分布在 E ≠ 0 的全空间 分布在 B ≠ 0 的全空间
能量密度对场量的关系 二次型（E²，体现非线性叠加） 二次型（H²，体现非线性叠加）

7.4 容易混淆的几个概念

概念 公式 区别
电场力对电荷做的功 W = Q(φ₁ − φ₂) = ∫ Q E·dl 移动电荷的过程量，不是储存的能量
电场能量 W_e = ½ ∫ D·E dV 建立场的过程中储存的状态量
磁通量 Φ = ∫ B·dS 穿过面积的磁感应线总数
磁场能量 W_m = ½ ∫ B·H dV = ½ LI² 建立电流场的过程中储存的状态量

快速记忆

  • 能量密度：电½D·E，磁½B·H，都是场量的二次型
  • 总能量三条路：场积分 → 做功公式 → 电路公式，根据已知条件选
  • 谁做的功？静电场靠外力搬电荷，磁场靠电源抵反电动势

8. 静电场、恒定电场、恒定磁场各是什么场 + 基本方程

场的分类看两个量：散度（是否有源）和旋度（是否有涡旋）。

场 类型 散度方程（有源/无源） 旋度方程（有旋/无旋） 基本特点
静电场 有源无旋场 ∇·D = ρ （有源，电荷是源） ∇×E = 0 （无旋，可引入标量势 φ） E 线起于正电荷止于负电荷，不闭合
恒定电场 有源无旋场（传导区） ∇·J = 0 （无源，恒定电流闭合）
∇·D = ρ （仍有源，自由电荷）		 ∇×E = 0 （无旋，仍可引入 φ） J 线连续闭合，E 线在电源非库仑区不闭合
恒定磁场 无源有旋场 ∇·B = 0 （无源，无磁荷） ∇×H = J （有旋，可引入矢量位 A） B 线是闭合的环形曲线

三类场的对比汇总

对比项 静电场 恒定电场 恒定磁场

基本场量 E, D E, J B, H
散度 ∇·D = ρ ∇·J = 0 ∇·B = 0
旋度 ∇×E = 0 ∇×E = 0 ∇×H = J
位函数 φ (标量势) φ (标量势) A (矢量势), φ_m (标量磁位)
场的性质 有源无旋 有源无旋 无源有旋
