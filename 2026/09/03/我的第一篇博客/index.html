使用 Hexo + Fluid 搭建个人博客完整指南

前言

花了几个小时搭建了这个博客，记录一下过程，也给想建博客的朋友一个参考。

为什么选 Hexo？

对比了几种方案：

方案 优点 缺点
WordPress 功能强大、插件多 需要服务器、维护成本高
Hugo 速度快 主题生态不如 Hexo
Hexo 主题丰富、部署简单 需要 Node.js 环境

最终选了 Hexo，主要因为：

  • 免费托管在 GitHub Pages，不用买服务器
  • Fluid 主题颜值高、中文文档好
  • Markdown 写文章很舒服
