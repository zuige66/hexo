零基础教你用 OpenCode：让 AI 帮你写代码

前言

OpenCode 是一个在命令行里运行的 AI 编程助手，可以让 AI 帮你写代码、改 bug、解释代码，甚至帮你搭建项目。完全免费，今天教你怎么用。

你将学到：

  • 怎么打开命令行（CMD）
  • 安装 Node.js
  • 安装 OpenCode
  • 切换免费模型
  • 用 AI 帮你干活

第一步：打开命令行

很多人第一步就卡住了——命令行是啥？怎么打开？

Windows 系统

方法一：最快的方式（推荐）

  1. 按键盘上的 Win + R 键
  2. 会弹出一个小窗口
  3. 输入 cmd
  4. 按回车

就这样，一个黑色窗口出现了，这就是命令行。

方法二：从开始菜单

  1. 点击左下角 Windows 图标
  2. 输入 cmd 或 命令提示符
  3. 点击”命令提示符”

方法三：PowerShell（一样的用法）

  1. 在 Windows 搜索框输入 powershell
  2. 点击”Windows PowerShell”

提示：CMD 和 PowerShell 都能用，命令是一样的。

第二步：安装 Node.js

OpenCode 是用 Node.js 写的，所以要先装它。

2.1 下载 Node.js

  1. 打开浏览器，访问：https://nodejs.org
  2. 你会看到两个下载按钮
  3. 点击左边的 LTS（长期支持版） 下载
  4. 下载完成后双击安装包

2.2 安装 Node.js

安装时注意：

  1. 一路点 Next 就行
  2. 有一个页面问你要不要装其他东西，全部保持默认勾选
  3. 点 Install 开始安装
  4. 等安装完成，点 Finish

Q：提示”权限不够”？

A：Windows 用户右键命令行，选择”以管理员身份运行”。
