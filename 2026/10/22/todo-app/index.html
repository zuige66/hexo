Todo一句话待办软件

前言

　　记一件待办，多数软件要依次点新建、选日期、滚时间、填标题、设提醒，六个动作下来，事情本身反而成了负担。Todo 把这件事压成一行字：写下「明天下午4点 交周报」，日期、时间和提醒它自己排好；只写「买牛奶」，就安静地放进「无日期」里。

　　它简单、离线、不打扰。没有日期选择器、没有分类标签、没有账号，待办数据全部留在本机，除了检查更新之外不联网。装上就能用，不需要 Root 或任何框架。

一、下载安装

下载地址

  • GitHub 发布页：Todo Releases（含历史版本）
  • 最新版国内直链：todo-0.9.3.apk

　　只从 GitHub Releases 或本博客直链下载正式签名包。

安装前提

项目 要求
系统 Android 8.0（API 26）及以上
权限 通知、精确闹钟（设置内一键跳转）
网络 仅检查更新时联网，待办数据全程留本机

安装步骤

  • 下载 APK 后点击安装；首次安装若提示「未知来源」，按系统引导开启对应权限即可。
  • 装好后授予通知权限与精确闹钟权限。
  • 打开应用，直接在顶部输入框写一句话。

　　成功标志：首页出现「无日期」分组，输入框下方实时显示解析出的日期与时间。

二、一句话输入

　　记一件事只需要一行字。写下日期、时间和事情，剩下的部分自然变成详情，不用再分栏填选。


一句话待办
输入「周五下午开会」，下方直接给出 10月23日 周五 14点 与标题「开会」

支持的日期写法

类别 写法
相对天 今天、明天、后天、大后天
本周 周四、礼拜四、本周四
下周 下周四、下下周四（+2 周）
月日 1月2日、十二月三十一号
纯日号 5号、十五号
数字短日期 1.2 / 26.1.2（分隔符支持 . - /）

支持的时刻写法

  • 15:30、3点、下午3点、晚上11点
  • 3点半、3点一刻、3点三刻、3点20分

　　只写时段也能用：早上 08:00、中午 12:00、晚上 18:00、夜里 22:00。「今晚8点」会自动算成今天 20:00。

几个刻意的处理

  • 本周已经过去的星期 → 提示写错了，不会偷偷推到下周；
  • 没写年份、算出来是过去的日期 → 顺延到下月或明年；
  • 写死了年份、算出来是过去 → 提示；
  • 一句话里有多个日期 → 生成多条待办，一次录完。

时间段：一件事跨好几天

　　出差、值班、赶一个周期很长的活，不是某一天的事。写成一段就行：

写法 解析结果
25号到1号 出差 10月25日 – 11月1日
周一到周五 值班 本周一到本周五
10月21日到23日 交材料 三天区间
3天内 交方案 今天起 3 天

　　逾期只认最后一天，中间几天是正常状态。首页右侧会显示「还剩 N 天」「最后一天」这样的状态，日期显示成 25–31日 的紧凑区间。

　　开始那天早上（按设置里的默认时刻，默认 9 点）会收到一条「今天开始」，结束那天则按最后一天的时间到点提醒。

　　单日待办想改成时间段，不用重打一遍句子：在预览卡片上点「+ 时间段」，一次选起止日期即可。

三、首页与分组

　　待办按板块分组，顺序可调、可隐藏：

  • 逾期：过了时间还没做的，统一标红；
  • 有日期：未来的待办，内部再分「今日 / 明天 / 后天 / 本周 / 下周 / 更晚」，可多选；
  • 无日期：只记了一件事、没定时间的。

待办列表
逾期标红，按本周 / 更晚分组，右下角一键添加

　　列表会自己刷新，从「今天」翻成「已逾期」，不需要退出重进。

四、提醒与逾期

　　写了时间，Todo 会准时提醒，不靠后台常驻。一条待办可以有多重提醒：

时刻 内容
提前 7 天 提前一周提醒
提前 3 天 提前 3 天提醒
提前 1 天 明天到期
提前 1 小时 1 小时后到期（仅写了精确时刻）
到点 该办了
逾期后 还没完成，按间隔反复提醒（默认每天）

　　通知上直接带「完成」按钮，点一下就变成已完成，按钮转成「撤回」，不会堆出第二条通知。通知正文是一句小文案，同一条待办从头到尾都是同一句。

五、完成与重复

  • 点一下圆圈：标记完成，动画走完自动归档，中途滑走或切页也不会丢；
  • 右滑卡片：快速归档，没滑够会自动弹回。

归档列表
完成或删除的待办都在这里，可恢复或删除

　　给待办加重复（每天 / 每周 / 每月）后，完成它不会归档，而是顺延到下一次：每天 8点 吃药 完成后自动变成明天 8:00。重复任务永远只有一条。

六、外观与设置

  • 支持浅色、深色、跟随系统三种模式；
  • 11 套配色（平衡 6 套、鲜艳 5 套），深色卡片底色三档可选；
  • 手势可以单独关：右滑归档、长按编辑、双击编辑，各有一个开关；
  • 沉浸式顶栏：下滑时标题栏收起，上滑立刻回来，可关闭；
  • 通知标题可以自定义，提醒文案池也能改。

　　底部四个入口：Todo / 归档 / 设置 / 关于。关于页能「检查更新」，发现新版直接下载安装。

七、桌面小组件

　　不打开应用也能看今天要做什么。小组件 2×2 起步，横竖都能拉大：小尺寸显示 4 条，拉高自动变 6 条。行首的圆圈点一下就完成，不用进应用。

  • 日期显示四个开关：显示日期、日期位置（右侧 / 标题下方）、只显示日期、隐藏头部；
  • 事件优先：标题太长、和日期抢宽度时先保谁——默认保标题，日期变省略号；关掉则反过来；
  • 组件头部显示活跃待办总数，圆角跟随系统组件风格；
  • 在桌面搜「Todo」或「待办」都能找到这个组件。

八、已知限制

  • 最低 Android 8.0，低于此版本无法安装；
  • 通知上的「完成」按钮，在部分国产系统里要展开通知才看得到；
  • 除了检查更新，应用不联网。
