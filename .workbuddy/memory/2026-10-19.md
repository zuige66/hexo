## 顺带修复：10-18 壁纸闪烁修复引入的 404 回归

### 现象
浏览器控制台 404：`https://blog.zuiges.com/archives/rgb(111,%20155,%20216`。用 CDP 抓 initiator 得到 `type: parser`、位置在文档末尾，判断是运行时动态创建的 `<img>`。

### 根因
`themes/fluid/source/js/events.js` 的 `registerImageLoadedEvent()` 原代码：

```js
var src = bg.style.backgroundImage;
var url = src.match(/\((.*?)\)/)[1].replace(/(['"])/g, ''); // 假设一定是 url(...)
```

**它假设 `#banner` 行内背景一定是 `url(...)`**，用正则抓第一个括号内容去预加载图片。而 10-18 的闪烁修复把 banner 默认底色改成了 `linear-gradient(rgb(111, 155, 216), ...)`，于是正则提取出 `rgb(111, 155, 216` 当作图片 URL 请求 → 404。（副作用：NProgress 的 `inc(0.2)` 也顺带不触发。）

### 修复
改成显式只认 `url()`：

```js
var src = bg.style.backgroundImage || '';
var urlMatch = src.match(/url\(['"]?(.*?)['"]?\)/);
if (urlMatch) { /* 预加载 */ }
```

渐变场景（无 `url()`）直接跳过；降级 fallback 挂 `url('/img/default.png')` 时仍正常预加载。

### 定性说明
该 404 在**线上旧版同样存在**（当时线上还没部署本次动态改动），证实是 10-18 修复的回归，与本次动态功能无关。仅影响控制台报错与进度条微调，不影响页面功能。

### 本轮踩坑（红线）
1. **`.archive-tabs`（胶囊底板）不能删**：改居中时一度把 wrap 直接套在按钮外、删掉了底板容器，症状是 `wrap.querySelector('.archive-tabs')` 返回 null（脚本静默失效）+ 视觉上丢掉分段控件的底板背景。正确结构永远是三层：`.archive-tabs-wrap`（居中）> `.archive-tabs`（inline-flex 底板）> `.archive-tab`（按钮）。

## 订阅朋友圈：默认收起 + 收起展示 9 张（三行）（13:00）

zuige 要求：朋友圈加收起/展开，**默认收起，收起时展示 9 个（即三行）**。

### 实现方案
- 朋友圈网格原是 `repeat(auto-fill, minmax(230px,1fr))`（桌面 4–5 列），收起 9 个视觉不齐。改为**桌面/平板固定 3 列** `repeat(3,1fr)`，3×3 正好九宫格；手机仍 `1fr` 单列。
- 收起态 CSS：`#circle-feed.is-collapsed .feed-card:nth-child(n+10){display:none}`（只显示前 9 张）。
- JS（`circle-feed.js`）：渲染后 `setupToggle(total)` —— `total>9` 时给 `#circle-feed` 加 `is-collapsed`（默认收起）并 `insertAdjacentElement('afterend', button)` 注入按钮；文案"展开全部 N 篇"↔"收起"切换；`total<=9` 不折叠无按钮。`circle-feed.js?v=3 → ?v=4`。
- 新增 `.circle-feed-toggle` 胶囊按钮样式（居中、hover 上浮、dark 模式边框调亮）。
