## 新增「动态（Moments）」板块：放进归档页做双视图切换

### 方案（先讨论后动手）
给了两个存储方案供选，zuige 选了 **B：独立数据文件 `source/_data/moments.yml`**（另一个是「文章 + `moment: true` front-matter 标记」）。

选它的理由：动态不计入「共计 N 篇文章」的统计口径，也不挤占归档分页（`_config.yml` 里 `archive_generator.per_page: 100`，当前 13 篇）。样式选了**时间线卡片流**（非极简列表）。

### 关键坑（红线）
1. **`archive-list.ejs` 被三处复用**：`archive.ejs` / `category.ejs` / `tag.ejs`。动态相关 DOM 必须用 `params.key === 'archive'` 收口，否则会泄漏到分类页和标签页。
2. **软导航后内联 `<script>` 不执行**：`soft-nav.js` 只替换 `#board.innerHTML`，内联脚本不会跑。所以 `moments.js` 必须用 `document` 级事件委托绑点击 —— 若写成内联 `onclick` 或一次性初始化，从其他页软导航进归档页后按钮就失效。
   - 好消息：`soft-nav.js` 第 157 行已派发 `softnav:loaded` 事件，`moments.js` 监听它重新初始化即可，**无需改动 soft-nav.js**。
3. **YAML 日期要加单引号**：`date: '2026-10-19 00:50'` 写成字符串，避免 YAML 自动解析成 timestamp 带来时区/格式意外。
4. 改 `custom_css` / `custom_js` 后**必须 bump `?v=N`**，否则浏览器缓存旧文件，表现为「改了没生效」。

## 顺带修复：10-18 壁纸闪烁修复引入的 404 回归

### 现象
浏览器控制台 404：`https://blog.zuiges.com/archives/rgb(111,%20155,%20216`。用 CDP 抓 initiator 得到 `type: parser`、位置在文档末尾，判断是运行时动态创建的 `<img>`。

### 根因
`themes/fluid/source/js/events.js` 的 `registerImageLoadedEvent()` 原代码：

```js
var src = bg.style.backgroundImage;
var url = src.match(/\((.*?)\)/)[1].replace(/(['"])/g, ''); // 假设一定是 url(...)
```

**它假设 `#banner` 行内背景一定是 `url(...)`**，用正则抓第一个括号内容去预加载图片。而 10-18 的闪烁修复把 banner 默认底色改成了 `linear-gradient(rgb(111, 155, 216), ...)`，于是正则提取出 `rgb(111, 155, 216` 当作图片 URL 请求 → 404。（副作用：NProgress 的 `inc(0.2)` 也顺带不触发。）

### 修复
改成显式只认 `url()`：

```js
var src = bg.style.backgroundImage || '';
var urlMatch = src.match(/url\(['"]?(.*?)['"]?\)/);
if (urlMatch) { /* 预加载 */ }
```

渐变场景（无 `url()`）直接跳过；降级 fallback 挂 `url('/img/default.png')` 时仍正常预加载。

### 定性说明
该 404 在**线上旧版同样存在**（当时线上还没部署本次动态改动），证实是 10-18 修复的回归，与本次动态功能无关。仅影响控制台报错与进度条微调，不影响页面功能。

## 追加：首页与侧栏也展示动态

zuige 追加要求「首页也加上」「首页侧面也增加」，于是在 `themes/fluid/layout/index.ejs` 加两处入口：

| 位置 | 元素 | 内容 |
|------|------|------|
| 首页正文（右栏文章列表上方） | `.home-moment-stream` | 最近 2 条，完整 Markdown，复用 `.moments-timeline` / `.moment-card` |
| 首页侧栏（热力图下方、`.home-side-sticky` **之前**） | `.home-moment-card` | 「最新动态」，最近 3 条纯文本单行截断 + `title` 悬浮全文，底部「查看全部动态 →」 |

关键设计点：
1. **侧栏卡片特意放在 `.home-side-sticky` 外面**——sticky 容器已有 `max-height: calc(100vh - 76px - 16px)` 且内容超出需滚动，再加一张卡片会挤占吸顶区。
2. 侧栏列表**复用既有 `.home-recent-list`**（自带单行 ellipsis，`home-sidebar.css` 第 64-66 行），几乎零新增 CSS，只补了「查看全部动态」入口样式。
3. 入口统一指向 `/archives/#moments`，构成「首页瞥一眼 → 归档页看全部」的路径。
4. 条数常量 `homeMomentLimit` / `sideMomentLimit` 放在 `index.ejs` 顶部，方便调整。

### 本轮踩坑（务必记住）
**改了 `source/css/*.css` 必须同步 bump `_config.fluid.yml` 里的 `?v=N`**。这次 `moments.css` 新增了首页样式，若不 bump（v1→v2），访客浏览器拿 CDN 缓存的旧 CSS → 首页新样式完全不生效，且症状极易误判成「模板写错了」。

另外，线上验证时发现 Cloudflare CDN（`via: 1.1 varnish`、`Cache-Control: max-age=14400`，4 小时）会缓存 Pages 构建**完成前**的 404：新资源首次 curl 得到 404，需带 `?cb=<时间戳>` 绕过或等 CDN 刷新后再验。判定「部署是否成功」别只看一次 curl 状态码。
