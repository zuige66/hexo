## 首页动态 Banner「云间列车」（方案 A 落地）

- 素材：Shadertoy `Ndc3zl`《Up in the Cloud Sea》（原作 mdb，CC BY-NC-SA 3.0），采用 Tyson Zhou 的单 Pass 移植版（github.com/choutianxius/csce646-digital-image）。
- 新文件：`source/js/cloud-sea.js`（WebGL2 引擎+shader 内嵌）、`source/img/cloud-sea-noise.png`（蓝噪声 256x256，16KB）。
- 配置改动：`_config.fluid.yml` 的 `custom_js` 追加 `/js/cloud-sea.js?v=4`；`footer.content` 追加署名行（CC BY-NC-SA 合规）。
- **关键教训**：蓝噪声纹理**不能平滑降采样**（LANCZOS 会把方差抹平→云层变平坦色带），必须用 `Image.NEAREST` 抽取采样点；shader 内 `/1024.0` 常量须与纹理尺寸一致（改为 `/256.0`，且 JS 拼接时要用字符串 `'256.0'` 保住浮点字面量）。
- 兜底机制：仅首页生效；<768px / prefers-reduced-motion / 无 WebGL2 / shader 编译失败 → 保持静态头图；帧耗时连续超标 → 先降 renderScale(0.75→0.5) 仍不行再整体退回静态；visibilitychange + IntersectionObserver 暂停渲染。
- 本地 playwright 截图验证：蓬松水彩云海+大桥+列车动画渲染正常；曾出现两 bug（JS 数字 256.0→"256" 整除编译错、纹理加载竞态导致 start() 空转黑屏）均已修复。
- 待办：提交推送 main → hexo deploy 上线。

  - 单文件自包含：CSS + JS + GLSL + 蓝噪声 base64（data URI）内嵌，双击即可 `file://` 打开。

- FRAG 与博客 cloud-sea.js v4 完全一致（仅多了 3 个调色 uniform 和后处理 3 行），调好后需人工回同步到 `source/js/cloud-sea.js` 并 bump `?v=N`。
